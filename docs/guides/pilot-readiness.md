# The pilot readiness list

What must be true before the pilot's first night, one line per check, with who is responsible and when it counts as done. Written 2026-10-28 for ticket #56 (map #29). It only lists the checks; running them belongs to the build and to the owners named here.

**How to read it.**
- **Owner** is who makes it true or does the check. *Martin*; *the lead* (the session Martin talks to); *an agent* (a build or research session the lead briefs); *the venue* (the pilot venue's owner or staff); *lawyer / accountant*.
- **Done when** is the evidence that closes the line. A line is closed by a file, a ticket, a decision or a note in the named place, never by someone's memory.
- **Source** says where the line comes from, so the reason can be looked up. The state is as the sources say it on 2026-10-28. Nothing in this file was run to write it.
- "The pilot venue" is never named here (this repository is public). Its POS is Mistral (D122); paying is Stripe (D126).
- The file is a list, not a plan. When a line closes, change its state in place and add the date; do not delete it.

**The short version for Martin.** Your own lines are marked *Martin*. They cluster in four places: send Mistral's list and the venue's questions (V1, V3, V4); take the law questions to the lawyer and accountant and decide what comes back (L1–L4); create the Stripe platform account and the restricted key (P1, P2); and run the next field visit, the rehearsal and the platform accounts (F2, F3, O2, O6). Everything else sits with the lead, an agent or the venue.
