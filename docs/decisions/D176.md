# D176: An online booking always asks for a phone; the switch that makes it optional covers only bookings staff enter

Martin, 11-26, answering the reservations part 2 lead's question "is a phone always required online?" with "Yes, always". It changes one line of D135 ("a phone is required by default, with a switch in reservation settings to make it optional"); the rest of D135 stands.

## Martin's decision

- **The booking page always asks for a phone,** whatever the venue's settings say. A request without a valid phone number is refused.
- **D135's switch stays, for staff only.** It still makes the phone optional on a booking a hostess or manager enters by hand.

## Why

The phone is what an online request is matched on: it finds the guest's record at the venue, and it is how the club reaches a party the email did not. A hostess taking a walk-up booking can see the party; the booking page cannot.

## Where it lives

- `packages/core/src/service/reservations/online.ts`: the online request refuses `invalid_phone`, and reads no switch.
