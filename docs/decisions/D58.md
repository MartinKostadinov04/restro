Haiku for simple exactly specified tasks, Sonnet by default, Opus only for genuinely complex work; avoid several Opus agents at once.

Model tiers for coding agents (amends D48): Haiku for simple tasks with exact, detailed instructions; Sonnet as the default; Opus only for genuinely complex work (core engine, security/crypto, data-integrity rules). Avoid several Opus agents at once — parallel agents hit the subscription's session limit (seen twice on 10-09)
