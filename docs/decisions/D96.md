# D96: Versions: live + up to 2 restorable, non-live purged after 30 days, change log 2 months

Versions: live + up to 2 restorable, non-live purged after 30 days, change log 2 months. Publish button top right on every tab (both modes), change count, confirmation; a dropdown per menu (areas in brackets, change counts) when several. Publishing tab: no "On guests' phones", no "Changes waiting"; Automation settings (POS only: sync mode + publish after sync); no new-items hold rule; banners only when relevant.

Publishing simplified (Martin 10-12). Versions: per menu, the live version plus up to 2 earlier ones can be restored; any version other than the live one is purged once it is older than 30 days, even if it is one of the last 2 (the live version is never purged); the change log (what changed, who, when) is kept 2 months, then purged. Publish button: top right of the venue page on every tab, in both automation modes (own edits always need publishing); greyed when nothing differs from the live menu, with the reason when publishing is blocked; shows the number of changes; the confirmation lists them. With more than one menu it becomes a dropdown: each menu by name with the areas it serves in brackets (D95) and its number of changes (the existing change categories drive the counts; per-area counts need new logic). "Open the guest page" sits beside it. Publishing tab: "On guests' phones now" and "Changes waiting" are removed; "Rules" becomes Automation settings, for POS venues only, holding the sync mode (D82, moved here) and "publish automatically after a sync"; the "new items from the till: show/hold" rule is removed (in automatic mode new till items go live without review; the >30% hold stays). Banners only when they apply: held publish, paused after a return, address switched off. "Overrides to review" moves to the composer as an item badge. Refines D82 and D59
