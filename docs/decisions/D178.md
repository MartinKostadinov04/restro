# D178: Until the club has its own website, only the address configuration names may frame the booking page

Martin, 11-26, answering the reservations part 2 lead's question for #581 (the club's website address) with "Use staging only". The pilot club has no website yet. It refines D136's "Embedding is allowed by naming the venue's own site as the page's permitted frame ancestor; anything else is refused."

## Martin's decision

- **For now, the booking page may be framed only by its own origin and by the addresses one environment variable names,** for testing on staging (#581). Any other site is refused.
- **No address is written into the code.** Staging starts on a temporary address and moves to its own domain later (D172), so the address comes from each environment's configuration.
- **The venue's own site comes later, as a venue setting** the owner fills in Settings › Reservations (#609), when the club has a website. D136's rule then applies as written, next to the configured addresses.
