# D68: Public address <base>/m/<slug>-<code>

Public address `<base>/m/<slug>-<code>`: a random permanent 12-character code finds the venue; slug cosmetic, editable, not unique; QR stickers keep `/t/<token>`.

Public menu address = readable name + permanent random code (Martin, 10-11: "like Claude handles its artifacts… restro.com/club-menu/hash; don't reinvent the wheel"). The address is `<base>/m/<slug>-<code>`, the same pattern as Claude artifacts, Notion and Medium:
- `<code>` is a random 12-character lower-case code per venue, from `crypto`, never derived from an internal id. It is unique and permanent, and it alone finds the venue.
- `<slug>` is cosmetic and editable. A stale or missing slug still works, and the page corrects the address bar.
- Slugs no longer need to be unique (this replaces T61's global unique slug).
- Published files are keyed by the code (`v/<code>.json`). QR stickers keep using `/t/<token>`, unaffected.
- Random codes also stop anyone listing all venues by guessing addresses.
