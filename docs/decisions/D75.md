# D75: When barsy has no public name for an item, option or category, Restro shows barsy's…

When barsy has no public name for an item, option or category, Restro shows barsy's own name (`article_name`, `cat_name`) and the composer warns that the menu name is missing; no other internal field ever reaches a snapshot.

barsy's own name stands in for a missing menu name (Martin 10-11, after a new venue showed 59 nameless Burgers items: "till name is used but with a warning that item name is missing"). barsy gives every article and category its own name (`article_name`, `cat_name`: what the till shows) and an optional public name for guests (`article_name_public[_ml]`, `cat_name_public[_ml]`). When the public name is empty, Restro uses barsy's own name for the item, option or section, and the composer warns on it ("menu name missing in the till; its own name is shown") until someone fills the public name in barsy or types a name in Restro. This narrows CLAUDE.md's "never put internal names in a snapshot" to everything except this fallback; ids, cost prices, internal notes and every other internal field stay out
