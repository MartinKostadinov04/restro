# D86: Venue states: Draft

Venue states: Draft (never published or unpublished), Live, Archived (bin, D83). All venues card: display name, state, POS instance (or By hand), the POS's venue name, link to the full menu preview (not a table's view; its design comes later).

Venue states and the All venues card (Martin 10-12). Every venue shows one state: Draft (never published, or taken offline: implies an "Unpublish" action that withdraws the guest files without deleting), Live (published), Archived (deleted, in the organisation's bin until purged by the 30-day clock or by hand, D83). Each card in All venues shows: the display name, the state, the POS connection (instance name, or "By hand"), the venue's name in that POS, and a link to the full menu preview: the venue's whole menu, not a table's view. What that preview looks like is decided with the design
