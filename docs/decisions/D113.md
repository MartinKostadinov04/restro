# D113: Payment mode per item, with one switch per table; Restro is the gatekeeper

Martin 10-18. Decided while charting map #29 and sharpened in the grilling of "What is a bill in Restro?" (#35).

Each item has a **payment mode**: **on the bill** or **pay first**. It is set as a venue default with an override per item, next to D29's ordering mode. Each table has one switch in the tables screen, **"Disable prepayments"**, off by default. When it is on, everything ordered at that table goes on the bill. Martin chose this single switch over three settings per area ("items decide / everything on the bill / everything paid first"). A venue that wants a table to pay first for everything marks its items pay-first.

The rule lives only in Restro, as a gatekeeper. The POS only ever sees POS bills and payments, never the rule. How a bag with pay-first items is paid and sent is D112.

Supersedes D5's "an order is paid when placed": payment now depends on the item and the table, not on the order.
