# D158: Restro opens inside the venue

Plan: `docs/deliverables/2026-11-18-navigation-and-feature-bases.md`.

## Proposed

- An organisation with **one venue**: signing in opens that venue (its Studio for an owner), not the venues list.
- With **several venues**: the one this person used last, never one they no longer have.
- **All venues** stays one tap away in the venue switcher.
- Staff keep D141's landing.

## Recommendation

Yes: one tap off every story for a one-club owner, which the pilot is.
