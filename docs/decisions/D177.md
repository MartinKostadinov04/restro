# D177: A hostess may confirm an online request without giving it a spot; the spot can be set later

Martin, 11-26, answering the reservations part 2 lead's question "must a spot be picked before Confirm?" with "Yes, spot later". It changes D136's "a booking that arrives without a table always waits for a hostess to give it one": the booking still waits for a hostess, but her Confirm does not have to carry a spot.

## Martin's decision

- **Confirm is allowed without a spot.** A request confirmed without one becomes Reserved with no spot, and a hostess gives it one later, as with any booking taken without a spot.
- **Automatic confirmation is unchanged** (D136): it applies only where the guest picked their own spot.

## Where it lives

- `packages/core/src/service/reservations/answer.ts`: `reservation.confirm` takes the spots it is given, or keeps what the request holds, and that may be none.
- `apps/web/src/reservations/confirm-request.tsx`: the dialog's Confirm is not held back by an empty pick.
