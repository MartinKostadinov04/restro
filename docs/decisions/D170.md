# D170: A song request carries no table, and the way in is the venue's own menu

Martin, rounds 2 and 4 of the grilling of the Club Biad song-request prototype. Decision log: `docs/deliverables/2026-11-22-song-requests-decision-log.md` (rows 1.8, 1.24). Spec: [#520](https://github.com/MartinKostadinov04/restro/issues/520), feature set 4. This is the question D99 and D100 both left to T81, and it closes it.

## Decided

- **A song request needs no table code, and is never attributed to a table** (row 1.8). This is the declaration D100 asks every guest feature to make, and song requests declare **no**. Ordering, the bill and calling a waiter keep the requirement, because they act on a table in the POS; a song request touches no POS at all.
- **The table is deliberately not written onto the request,** even though the session does know it (D121). Not "unavailable": not recorded.
- **The way in is the venue's own menu.** The table's QR opens the menu as it does today, and the **menu's navigation holds that venue's song-request link**. So the venue's identity arrives with the page the guest already has, and nothing new is printed.
- **A venue-level address exists as well,** for a code on the club's screens or a poster, for guests who are standing. It costs nothing on top of the link in the menu.
- **Identity is D121's guest session,** not a table token: scoped to the venue and the service day (D165).

## Why

In a club most of the room is standing, so a feature that needed a table would shut out the people most likely to use it. Martin's answer in round 2 was "no table at all", and round 4 then put the entry where it costs nothing: the menu every guest already has open.

Writing the table onto the request would have been free to do and hard to undo — it would make a song request look like a table's order, invite a bill, and attribute to a table something that is not the table's. The three other conditions of D71 stand unchanged: the venue switched the feature on, the platform supports it, and the channel is interactive.

## Not decided here

What the menu's navigation entry looks like, which is the menu designer's (D128 to D131) and the screen plan's (D123).
