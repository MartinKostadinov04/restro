# D106: The design-skill set in force

Martin 10-17, after a trial of two skills on the Design tab and the Editorial Market face and a due-diligence pass. A design skill is added one at a time and only after: provenance and licence; a reading of every file it loads, runs or fetches; a conflict check against the nine rules and the designer guide; an overlap check against what the repo already says; a trigger check; a cost check; and a trial on real screens. An adopted skill is copied into the repo at a pinned commit, and updated only through an Upkeep ticket.

- **Anthropic frontend-design** (Apache 2.0; `anthropics/skills`, skill last changed in commit `41bbe19`, read at HEAD `dbd4588`): adopted as the visual-direction layer of the `template-design` skill only. It is vendored verbatim under that skill's references, with a Restro overrides file that is read first: colour, font, radius and shadow come from the theme tokens, never a hex palette or a typeface choice; no hero or landing page, the first screen is the menu; no invented copy, the words come from the view model and the shell's strings; motion only in answer to a tap; the designer guide's §7.5 wins on quality. It is never a standalone skill: its trigger would fire on admin screens, where distinctiveness is not wanted (D107).
- **Vercel web interface guidelines** (MIT; `vercel-labs/web-interface-guidelines`, `command.md` at `434b7f9`, 2026-10-05): adopted as a pinned audit checklist with the Content & Copy section removed (Bulgarian and English interface text uses sentence case through next-intl) and a Restro overrides file that wins on conflict: no `Intl` or money arithmetic in a face, never truncate a name, every item in the markup, host-only page rules stay with the host. Used by the template reviewer and as a review step for admin UI diffs. Restro writes its own short copy rules instead of reviving Vercel's section. Vercel's own skill fetches the rules live from the internet on every run; the pinned copy is used instead.
- **UI UX Pro Max:** rejected. For a hospitality prompt its generated design system was a consumer landing page (Google Fonts, a hex palette, a scroll-reveal animation library), each against our rules, and its few useful points were already covered by the Platform port map and the Vercel rules.
- **Matt Pocock's skills** stay the planning and engineering foundation; `prototype` is the tool for direction variants (D105).
