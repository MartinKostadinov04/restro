# D87: A venue's source is fixed at creation

A venue's source is fixed at creation (no "Change"; new source = new venue, delete the old). A POS venue's menus: D88; sections and items are the composer's job. Supersedes D78.

A venue's source is fixed when it is created; the menu is chosen automatically (Martin 10-12: "you can't change the venue from the venue, that confuses"; "I would rather set up the venue from scratch with the new connection"). No "Change…" on the venue: to use another till venue, another POS, or to go from hand-made to a POS, create a new venue from that source and delete the old one (D83). Only the source is fixed: names, address, profile, languages and every other venue setting stay editable. Switching a hand-made menu to a POS is not supported in this version of the platform (may be revisited later). Supersedes D78 (no source-change archive flow). Menu category: refined by D88 (a barsy venue's menus are the roots barsy designates; the public menu is live by default). Choosing which sections and items appear is the composer's work
